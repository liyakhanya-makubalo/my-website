## Project Overview

Lilitha's Nature Relief is a website project designed to provide information about the organisation and the services it offers.

The website is designed to be simple, easy to use and easy to navigate. It allows visitors to learn more about Lilitha's Nature Relief, view the services provided, view projects, book a consultation and find contact information.

---

## Website Goals and Objectives

The main goal of the website is to create an informative and user-friendly online presence for Lilitha's Nature Relief.

## Key Features and Functionality

The website includes the following main features:

### Home Page

The Home page introduces visitors to Lilitha's Nature Relief and provides an overview of the organisation.

### About Us

The About Us page provides information about the organisation, its background, mission, vision and goals.

### Services

The Services page explains the services offered by Lilitha's Nature Relief.

The services include:

* Soil Testing
* Irrigation Planning
* Crop Monitoring
* Greenhouse Management
* Drone Crop Inspection

### Projects

The Projects page displays information about projects related to the organisation.

### Book a Consultation

The consultation page allows visitors to provide their details and request a consultation.

The page includes:

* Client details
* Contact details
* Preferred consultation date
* Description of requirements
* Consultation request form

### Contact Us

The Contact page provides ways for visitors to communicate with Lilitha's Nature Relief.

It includes:

* Contact number
* Email address
* Physical address
* Location/map
* Contact form

### Sitemap

The Sitemap page shows the structure of the website and provides links to the main pages.

### Part 2 Technical Requirements

The website uses the following technologies:

**HTML5**

HTML5 is used to create the structure and content of the website.
Semantic HTML elements such as header, nav, main, section, article
and footer are used.

**CSS3**

CSS3 is used to control the appearance and layout of the website.
This includes colours, fonts, buttons, forms, cards, images and
responsive layouts.

**Responsive Design**

CSS media queries are used to allow the website to adapt to
different screen sizes, including desktop, tablet and mobile devices.

**Forms**

HTML forms are used on the Consultation and Contact pages.
Required fields are included to help ensure that users complete
the necessary information.
