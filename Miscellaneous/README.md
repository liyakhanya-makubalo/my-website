# Lilitha's Nature Relief Website

## 1. Project Overview

Lilitha's Nature Relief is a website developed to provide information about the organisation, its services, projects and consultation options. The website allows visitors to explore the different pages, view images, learn more about the services offered and contact the organisation through online forms.

The website is designed to be user-friendly, responsive and easy to navigate on desktop computers, tablets and mobile devices.

## 2. Website Objectives

The main objectives of the website are to:

- Introduce Lilitha's Nature Relief to visitors.
- Provide information about the organisation and its services.
- Display projects and images in an organised gallery.
- Allow visitors to make enquiries and request consultations.
- Improve communication between the organisation and its visitors.
- Provide an accessible and interactive browsing experience.

## 3. Technologies Used

The website was developed using the following technologies:

- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used to style the website and create a responsive layout.
- **JavaScript:** Used to add interactive features and dynamic functionality.
- **Leaflet:** Used to display an interactive map.
- **FormSubmit:** Used to process and send online form submissions.
- **GitHub Pages:** Used to host and publish the website online.

## 5. Website Pages

The website contains the following pages:

- **Home:** Introduces Lilitha's Nature Relief and provides an overview of the website.
- **About Us:** Provides background information about the organisation.
- **Services:** Displays the services offered.
- **Projects:** Showcases projects and images in a gallery.
- **Book Consultation:** Allows visitors to request a consultation.
- **Enquiry:** Provides an online form for general enquiries.
- **Contact:** Displays contact information and location details.
- **Site Map:** Helps visitors find and access the different website pages.

## 6. Interactive Features

The website includes several interactive features to improve the visitor experience:

- **Responsive navigation:** Allows visitors to move between website pages.
- **Image lightbox:** Allows visitors to click gallery images and view them in a larger display.
- **Interactive map:** Allows visitors to explore the displayed location.
- **Live search:** Helps visitors search and filter relevant website content.
- **Dynamic date and time:** Displays the current date and time.
- **Automatic copyright year:** Updates the copyright year using JavaScript.
- **Back-to-top button:** Allows visitors to return to the top of a page easily.
- **Form validation:** Checks that visitors enter the required information before submitting forms.
- **Form submission:** Uses FormSubmit to process online enquiries and consultation requests.

## 7. Search Engine Optimisation (SEO)

Basic SEO techniques have been included to help search engines understand the website. These include:

- Relevant page titles.
- Meta descriptions.
- Keywords related to the website.
- Canonical URLs.
- Open Graph metadata for social media sharing.
